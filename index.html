How to install

The installer is shipped as a split ZIP archive. Follow these steps in order.

1

Install 7-Zip

Download and install 7-Zip (free). Windows Explorer cannot open multi-volume archives on its own.

2

Download all parts

Save .zip.001{{PART_LIST}} into one folder. The total download is {{TOTAL_SIZE}}.

3

Extract

Right-click GXWorks2_1.620W.zip.001 → 7-Zip → Extract Here. Wait until all 932 files are extracted to GXWorks2_1.620W.

4

Run setup

Open the extracted folder and run setup.exe from the GX Works2 1.620W EU directory. Use an account with administrator rights.

5

Activate

Enter the serial number during setup. The serial is provided in GXWorks2-Serial Number.txt inside the archive.

FAQ

Common questions about the download and installation.

Why is the download split into parts?

GitHub limits each release file to 2 GB. The archive is split into parts under that limit. Download all parts into the same folder and extract the .001 file — 7-Zip joins them automatically.

7-Zip says the archive is corrupt

One of the parts is incomplete. Re-download the part whose SHA-256 does not match the checksum above. Make sure no part was renamed or downloaded twice with a different filename.

Can I extract with WinRAR or Windows Explorer?

WinRAR works if you open the .001 file. Windows Explorer's built-in ZIP support does not handle multi-volume archives — use 7-Zip.

Where do I get the serial number?

It is included in the archive as GXWorks2-Serial Number.txt. Use the serial during installation and keep it for future re-installs.

The installer does not start

Right-click the setup executable and choose Run as administrator. Also temporarily disable antivirus real-time scanning, which sometimes blocks older installers.
